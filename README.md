# پویش زمین — انتشار عمومی

این مخزن فقط برای انتشار نسخه‌های نصب، به‌روزرسانی و خروجی‌های عمومی وب برنامه‌های پویش زمین استفاده می‌شود.

- فایل‌های نصب و به‌روزرسانی نسخه‌های برنامه در بخش **Releases** قرار می‌گیرند.
- خروجی مستقل سه پنل وب باید در پوشه **web-release/** قرار بگیرد.
- راهنمای انتشار خودکار وب روی Cloudflare Pages در فایل [CLOUDFLARE_PAGES.md](CLOUDFLARE_PAGES.md) قرار دارد.
- Workflow انتشار: `.github/workflows/deploy-cloudflare-pages.yml`

کد منبع اصلی، داده‌های عملیاتی، پایگاه داده، Worker و تنظیمات خصوصی در این مخزن منتشر نمی‌شوند.

مخزن عمومی است؛ پیش از هر انتشار مطمئن شوید هیچ Secret، توکن، داده شخصی یا اطلاعات محرمانه‌ای در فایل‌ها وجود ندارد.
